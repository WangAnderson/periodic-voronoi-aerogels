# Aerogel Studio v0.2.0

将两套周期 Voronoi 微结构生成器封装为中文 Python 桌面软件，提供 Windows x64 免安装版。

## 下载与开始

- **Windows 免安装版**：下载 `AerogelStudio-Windows-x64-v0.2.0.zip`，完整解压，双击 `AerogelStudio.exe`。无需另装 Python，保留 `_internal` 依赖目录。
- **Python 源码**：下载 `AerogelStudio-Python-Source-v0.2.0.zip`，或克隆仓库并切换到 `v0.2.0` 标签。
- **中文说明**：附件 `AerogelStudio-User-Guide-zh.md`，或阅读仓库中的桌面软件教程。
- **完整性校验**：附件 `SHA256SUMS.txt` 记录各下载文件的 SHA-256。

首次可点击“载入示例”，无需等待完整尺寸计算即可旋转、缩放、检查和导出一个真实生成的结构。随后选择气凝胶类型、填写参数并生成自己的模型。

## 本次新增

- 氧化铝片层 / 纳米线气凝胶类型切换及对应参数表单。
- 变径纳米线：控制最小 / 最大直径、计算域、孔隙率、随机种子、采样和实体分辨率。
- GPU 三维预览、视角切换、视图保存、运行进度、停止计算和结果重载。
- 实体并集、胞元封口、网格质量和实体孔隙率容差检查。
- STL / STEP / OBJ / PLY 导出、坐标单位记录、Lumerical STL 导入脚本。
- 软件图标、示例项目、第三方许可证及封装脚本。

## 验证与适用范围

已完成两类模型的实际生成、Windows EXE 脱离 Python 环境的生成与四格式导出，以及 Open Cascade 对真实纳米线 STEP 的实体、面数和体积回读检查。详见 `STUDIO_VALIDATION.md`。

**STEP 是封闭分面 B-rep 实体，不是逐根解析圆柱的参数化 CAD。** 体素化存在空间离散误差，应比较更细分辨率。实际有限元体网格划分、材料参数、周期边界匹配及 FDTD 光源 / 监视器 / 求解仍需在目标软件中配置和核验。

原有命令行与 Spyder 入口继续可用；原命令行纳米线 STL 仍是展示网格，桌面新增的纳米线实体导出另有独立入口。

## English

Aerogel Studio v0.2.0 adds a Chinese desktop UI, variable-diameter nanowire solids, interactive 3D previews and STL / faceted STEP / OBJ / PLY exports. The portable Windows x64 ZIP includes the runtime, examples and documentation. Keep its entire folder intact. STEP files are faceted B-rep solids. Solver material models, volume meshing, boundary conditions and convergence remain the user's simulation setup tasks.

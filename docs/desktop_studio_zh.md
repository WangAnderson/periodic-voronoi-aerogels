# Aerogel Studio 中文使用说明

首次启动可点击“载入示例”，立即查看一个真实生成的 100 nm 变径纳米线模型；示例参数会同步到左侧表单。窗口内可直接旋转、缩放，也可导出该示例。随后修改参数并点击“生成微观模型”建立自己的结构。

Aerogel Studio 将氧化铝气凝胶片层模型和纳米线气凝胶模型放入同一个中文桌面窗口。选择模型类型后，左侧显示对应参数；右侧显示可旋转、缩放的三维结构。应用逻辑使用 Python 编写，界面使用 PySide6，三维视窗使用 PyVista/VTK。

本软件生成的是可复现的随机 Voronoi 几何微结构。材料成分、热导率、折射率以及实验结构的统计标定，需要在后续研究中另外确定。

## 1. 启动软件

### 使用打包版

在 [GitHub Releases](https://github.com/WangAnderson/periodic-voronoi-aerogels/releases/tag/v0.2.0) 下载 `AerogelStudio-Windows-x64-v0.2.0.zip`。本页对应 v0.2.0；版本变化见仓库的 `CHANGELOG.md`。

将发布压缩包**完整解压**到本机目录，再运行 `AerogelStudio.exe`。从源码构建时，程序位于 `dist/AerogelStudio/AerogelStudio.exe`。打包版不要求另行安装 Python。

请保留启动程序旁的全部依赖文件和子目录，不要只复制一个 EXE 到其他位置。可以为 EXE 创建桌面快捷方式。输出模型建议保存到“文档”或自己的项目目录，避免写入受保护的程序安装目录。

### 使用 Python 源码

需要 Python 3.11 或更新版本及兼容的依赖。在项目根目录打开 PowerShell，建议新建独立环境：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[studio]"
.\.venv\Scripts\python.exe run_aerogel_studio.py
```

`run_aerogel_studio.py` 是桌面软件入口。不要直接运行 `aerogel_studio/app.py` 或模型包中的 `cli.py`。在编辑器中调试时，应选择上述环境的解释器，并将入口设置为 `run_aerogel_studio.py`；避免在同一进程混用 PyQt5 与 PySide6。

## 2. 选择模型并设置参数

界面中的长度输入均为 **nm**；孔隙率直接填写百分数。例如输入 `95` 表示 95%，软件会转换为计算所用的 `0.95`。

两类模型共用的参数：

| 界面参数 | 含义及操作建议 |
| --- | --- |
| 气凝胶类型 | 选择“纳米线气凝胶”或“氧化铝气凝胶 · 片层”。下方的尺寸输入会随之切换。 |
| 目标孔隙率 | 希望达到的空隙体积分数；以结果中的独立核验和实体网格孔隙率判断实际结构。 |
| 计算域边长 | 立方体周期胞元边长。`1000 nm` 等于 `1 μm`。 |
| Voronoi 种子数 | 控制剖分密度。它不是最终纳米棒或片层数量；片层模型可选择“自动估算”。 |
| 随机种子 | 相同几何参数、随机种子和数值环境可复现随机结构。 |
| 实体体素间距 | 将物理结构实体化时使用的空间分辨率。数值越小，细节越多，内存、面数和导出开销也越大。 |
| 孔隙率采样 | 快速、标准和精细三档 Sobol 采样；采样越多，体积分数估计通常越稳定，但计算更慢。 |
| 孔隙率容差 | **绝对百分点**。填写 `0.5` 表示允许相差 0.5 个百分点，不是目标值的相对误差 0.5%。 |

纳米线模型的尺寸参数：

| 参数 | 含义 |
| --- | --- |
| 纳米线最小直径 / 最大直径 | 每条完整逻辑 Voronoi 边先在该范围内均匀随机分配直径，然后参与选边与体积计算。两个值相等时，得到固定直径模型。 |
| 纳米线长度 | 由 Voronoi 剖分决定，当前界面不提供独立线长约束。实际选中结构的长度统计保存在 `metadata.json`。 |

选边还受连通性和孔隙率约束，因此最终选中纳米线的直径直方图不必严格均匀。实体网格是这些变直径胶囊体的体素并集，交叠体积只计算一次。

氧化铝片层模型的尺寸参数：

| 参数 | 含义 |
| --- | --- |
| 片层厚度 | 片层有限厚度，独立于片径设置。 |
| 偏好等效片径下限 / 上限 | 选面时优先满足的等效片径窗口，不是所有片层必须具有的固定外形尺寸。为了保持周期连通，可能保留范围外的面；实际比例与片径统计见元数据。 |

默认纳米线设置为：1000 nm 胞元、16–24 nm 直径范围、400 个种子、95% 目标孔隙率、随机种子 42、5 nm 体素间距。片层模型默认使用 2.5 nm 体素间距，以更细地分辨 5 nm 厚片。更改尺寸、种子数或孔隙率后，不是所有组合都可行；软件会报告当前骨架策略是否达到要求。

## 3. 生成结构与三维预览

1. 选择气凝胶类型，填写结构和计算参数。
2. 在“文件输出”中选择需要的格式、导出单位及输出位置。首次可只选 STL，确认结构后再补导出其他格式。
3. 点击“生成微观模型”。计算在独立进程中运行，窗口仍可响应；下方显示当前阶段，“显示运行详情”可展开详细消息。
4. 完成后右侧加载三维结构，并显示独立核验孔隙率、实体网格孔隙率及完整网格三角面数。

三维视窗操作：

- **左键拖动：** 旋转；**滚轮：** 缩放；**Shift＋拖动：** 平移。
- “等轴测”“XY”“XZ”“YZ”用于切换标准视角。
- “胞元边框”只控制视窗辅助边框，不写入导出的实体模型。
- “保存当前视图”将当前构图保存为 PNG，使用两倍视口分辨率；放大软件窗口可增加图片像素尺寸。这不是固定 600 dpi 的导出设置。

大网格会尝试使用保持拓扑的简化预览，界面会提示。**简化只影响预览；STL、STEP、OBJ、PLY 始终从完整实体网格导出。** 预览不通过间隔抽取三角面来减量。

修改左侧结构参数不会改变已经生成的模型，必须再次点击“生成微观模型”才会创建新结构。“导出模型文件”针对当前右侧加载的结果；它只转换文件，不会重新抽取随机骨架。

## 4. 导出模型及单位

可在生成前勾选导出格式，也可在完成后选择新的格式和单位，点击“导出模型文件”指定保存目录。

| 格式 | 文件用途 |
| --- | --- |
| STL | 三角面封闭表面，便于查看器、体网格划分或其他软件导入；格式本身不保存可靠的长度单位。 |
| STEP | 由三角面构成的封闭分面 B-rep 实体，包含实体和单位定义；不是由解析圆柱、解析曲面组成的参数化 CAD。 |
| OBJ | 通用表面网格，便于三维软件继续查看或处理；导入时确认单位。 |
| PLY | 保留顶点和面连接关系的表面网格；导入时确认单位。 |

STEP 使用与 STL 相同的完整网格，不会通过改后缀生成。三角面越多，STEP 文件越大，CAD 导入、修复和体网格划分也可能越慢。几何封闭不等于已完成求解器网格验证。

默认导出单位为 **μm**。以 1000 nm 胞元为例：

| 导出单位 | 导出坐标中的胞元边长 | 从 nm 坐标乘以 |
| --- | --- | --- |
| nm | 1000 | 1 |
| μm（`um`） | 1 | 0.001 |
| mm | 0.001 | 0.000001 |

导出目录的 `coordinate_units.json` 为各模型文件记录坐标单位和缩放系数。导入 STL、OBJ、PLY 时应手动选择相同单位，并先检查外形尺寸。内部 VTP 缓存始终使用 nm，不随导出单位变化。

### Lumerical FDTD 导入模板

勾选 STL 后，会同时生成名称以 `import_` 开头的 `.lsf` 脚本。在对应导出目录中打开脚本，检查 STL 文件名和材料设置后再执行。脚本包含坐标到米的换算和一个 FDTD 区域模板，不会自动开始仿真。

默认折射率是占位设置，不是经拟合的氧化铝色散数据。应根据材料和波长修改材料数据库条目、光源、监视器及网格。模板的 x/y 周期边界适用于法向入射的周期结构；斜入射等情形需自行确认 Bloch 或其他适用边界条件。z 向 PML 对应有限厚度样品的设置。

软件没有运行 COMSOL、ANSYS 或 Lumerical 求解器，也没有声称验证这些软件中的完整热学、光学或力学求解流程。

## 5. 保存、重新打开及结果文件

每次生成会建立带时间和模型类型的独立子文件夹。点击“结果文件夹”可直接打开。

| 文件 | 说明 |
| --- | --- |
| `studio_result.json` | 桌面软件的完成清单。“打开已有结果”选择此文件。 |
| `studio_mesh.vtp` | 未简化的完整实体网格，内部坐标为 nm。 |
| `preview_mesh.vtp` | 界面预览网格；可能经过简化。 |
| `config_used.json` | 实际采用的生成参数。 |
| `metadata.json` | 几何、连通性、孔隙率估计和实体网格质量记录。 |
| `coordinate_units.json` | 已导出文件的坐标单位记录。 |
| `sheet_solid_*.…` / `nanowire_solid_*.…` | 按勾选格式和单位生成的模型文件。 |

两类核心生成器还可能保存几何 NPZ、壳 BDF、周期节点映射或其他辅助文件。重新打开结果时，请保留完整结果目录，特别是两个 VTP 文件及 `studio_result.json`；不要只复制 JSON。移动完整结果目录后，软件可以在清单旁寻找同名网格文件，请勿单独改动缓存文件名。

加载已有结果后，导出使用的是该结果的网格。其实际参数以该结果的 `config_used.json` 与元数据为准，而不是尚未重新生成的左侧输入值。

## 6. 分辨率、孔隙率与常见问题

**孔隙率至少有两种需要同时关注的数值。** 独立 Sobol 估计描述有限厚度片层或胶囊体物理并集；实体网格孔隙率来自体素化后封闭表面的体积。两者的差异反映采样与空间离散误差，不能用输入的目标值替代。两类桌面模型均检查最终实体网格是否落在目标容差内；纳米线还对独立采样结果执行容差检查。若网格超差，任务会提示减小体素间距，不能把留下的中间文件视为桌面软件已完成的结果。

减小体素间距可改善薄片、细杆和边界细节，但网格量随每个方向的分辨率立方增长。例如 1000 nm 胞元、5 nm 间距约为 200³，即 800 万体素；2.5 nm 间距约为 400³，即 6400 万体素。表面提取、质量检查、预览和 STEP 写入还会额外占用内存。

纳米线至少要求两个体素分辨最小直径，这只是最低运行条件，定量计算前仍应比较更细网格。周期三向贯通检查针对逻辑骨架；单胞边界裁剪后的实体可能包含多个封闭片段，需要在求解器中使用相应周期边界或平铺结构。

| 情况 | 处理方法 |
| --- | --- |
| 参数不合法 | 检查直径上下限、片径上下限和计算域尺寸；按弹窗提示调整体素间距。 |
| 报告目标不可达 | 查看运行详情和 `feasibility.json`。调整目标孔隙率、种子数或尺寸范围；可达范围取决于当前骨架策略。 |
| 独立核验超差 | 提高 Sobol 采样档位后重试，并核对结构是否接近可行边界。 |
| 实体网格孔隙率超差 | 减小体素间距；仅增加 Sobol 点数不能消除网格离散误差。 |
| 内存或 STEP 文件过大 | 先减少计算域或剖分规模、检查预览和 STL，再决定是否需要导出完整 STEP。 |
| 三维视窗初始化失败 | 展开运行详情查看显卡/渲染错误。生成和导出与三维视窗分开处理；应解决本机渲染环境后再进行交互预览。 |

点击“停止计算”会结束当前计算进程。未完成文件夹保留用于排查，不应作为最终模型使用。只有任务成功结束、`studio_result.json` 已写出并能够正常载入时，才表示桌面生成流程完成；单独看见 STL 或 `metadata.json` 不足以判断后续导出是否全部完成。

## 7. 源码结构与封装方式

| 文件 | 职责 |
| --- | --- |
| `run_aerogel_studio.py` | 桌面入口和独立计算进程入口。 |
| `aerogel_studio/app.py` | 参数窗口、GPU 三维预览、任务进度和文件操作。 |
| `aerogel_studio/worker.py` | 执行请求，并写出进度、成功或错误事件。 |
| `aerogel_studio/backend.py` | 统一生成适配、网格缓存、预览简化和格式导出。 |
| `aerogel_studio/variable_wire.py` | 变直径纳米线的并集采样、周期体素实体化及质量检查。 |
| `aerogel_studio/cad_export.py` | 封闭分面 STEP 和单位正确的 FDTD 导入脚本。 |
| `voronoi_aerogel/` / `voronoi_nanowire/` | 原有周期几何、拓扑、片层生成和纳米线基础工具。 |

界面通过 Qt 的 `QProcess` 启动独立计算进程，以 JSON 请求传递参数。计算进程将进度、成功或错误事件追加到 JSONL 事件文件，界面定时读取以更新窗口；不依赖无控制台 EXE 的标准输出。源码运行和打包版共用这条路径，通常无需手动调用 `--worker`。

封装采用包含依赖目录的 Windows 文件夹发布方式。建议使用 Python 3.13 创建全新环境，不使用 `--system-site-packages` 混入其他环境的依赖。需要重新构建时，在项目根目录执行：

```powershell
python -m venv .venv-build
.\.venv-build\Scripts\python.exe -m pip install -r requirements-studio-tested.txt
.\.venv-build\Scripts\python.exe build_studio.py
```

构建入口为 `build_studio.py`，产物位于 `dist/AerogelStudio/`。发布时打包整个产物文件夹，保留 `_internal`、许可证和使用说明，不要只分发 EXE。

构建前请先关闭正在运行的旧版软件，以释放 DLL 文件。自定义图标源文件位于 `aerogel_studio/assets/`；`build_icon.py` 可从 SVG 重建 PNG 和多尺寸 ICO。项目应用代码采用 MIT 许可证，随程序提供的第三方依赖保留各自许可证，见 `THIRD_PARTY_NOTICES.txt` 和 `THIRD_PARTY_LICENSES/`。
